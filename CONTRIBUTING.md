# Contributing

Keep changes narrow and preserve the distinction between the Claude Code and Codex adapters.

1. Explain the behavior or safety boundary being changed.
2. Add or update the smallest relevant route case or deterministic fixture.
3. Run `scripts/validate-release.sh` from the repository root.
4. For routing, authorization or orchestration changes, include fresh-context evidence and state its validation level.

Do not commit local profiles, transcripts, run manifests, attestations, secrets, absolute home paths, caches or generated bytecode. Do not vendor optional third-party skills into this repository.

Static validator output is not sufficient evidence for a behavior claim.
