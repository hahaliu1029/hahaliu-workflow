# 可选本地画像

公开版本不预设语言、浏览器、确认风格或项目习惯。当前用户消息、system/developer 指令、适用 `AGENTS.md`、项目 auto-skill 和 live 证据始终优先。

如果需要个性化，可以在本机维护不提交的 `profile.local.md`，只记录会反复影响路由的软信号，例如：

- 回答语言与结果呈现偏好。
- 页面验收必须使用的浏览器或真实登录态。
- 对脏工作树、增量复核和可用性分级的约定。
- 项目长期使用的验证入口或高风险边界。

安全底线不属于个性化偏好：未经当前请求明确授权，不执行 Git 写、发布、部署或外部副作用；完成声明必须引用当次证据。

只有同一偏好被用户明确重复至少两次，才建议写入本地画像；不要因单次例外修改公共 skill。
