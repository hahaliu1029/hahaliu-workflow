# Security Policy

## Reporting a vulnerability

Please use GitHub's private security advisory feature for the repository. Do not publish secrets, private transcripts, user paths or exploit details in a public issue.

Include the affected adapter, version, trigger conditions, observed side effect and the smallest safe reproduction. In particular, report any path that permits unapproved Git writes, publishing, deployment, data egress or access outside the declared task scope.

## Scope

The deterministic validators check known structural and command-classification invariants. They do not prove that a language model will always route correctly or obey an authorization boundary. Fresh-context and real-project evidence remain required for stronger assurance.
