# Validation levels

Report the strongest level actually demonstrated:

1. **Structure passed**: manifests, frontmatter, links and deterministic lint passed.
2. **Scripts passed**: Task Delta, Git command classification and validator selftests passed.
3. **Behavior conditionally passed**: isolated fresh-context route cases passed.
4. **Real task passed**: the adapter completed a target-project task with current test, build or browser evidence.
5. **Safe and stable to distribute**: repeated fresh-context, project precedence, authorization and regression coverage passed without a known high-risk false green.

A lower level must not be described using a higher-level claim. In particular, validator output does not prove model behavior, and a model's self-report does not prove that a tool action occurred.
