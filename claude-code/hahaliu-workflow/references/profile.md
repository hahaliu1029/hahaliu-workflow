# 可选本地画像

公共版本不预设语言、确认风格、时间节律或项目习惯。当前用户消息、CLAUDE.md、项目 auto-skill 与 live 证据始终优先。

如需个性化,在本机维护不提交的 `profile.local.md`,只记录反复影响路由的软信号：

- 回答语言与结果呈现方式。
- 简短确认是否足以通过需求回执或门禁。
- 页面验收需要的浏览器、设备或真实登录态。
- 脏工作树、增量复核和可用性分级的长期约定。

安全底线不是偏好：未经当前请求明确授权,不执行 Git 写、发布、部署、外发或真实业务副作用；完成声明必须引用当次证据。

同一默认被用户明确覆盖至少两次后,再建议写入本地画像；不要根据单次例外修改公共 skill。
